Overview and Summary

Conducted accessibility audits and implemented targeted UI fixes to improve web standards compliance on a client-facing website. Simultaneously produced social media content for a professional author's brand, including short-form video assets for Instagram Reels tied to book promotion campaigns. Collaborated directly with the client through iterative feedback cycles to refine deliverables and align content with marketing objectives.

Key Responsibilities

Web Accessibility Audits

Conducted accessibility audits using WAVE to identify front-end style issues and compliance gaps across the client-facing website.

UI Fixes and Improvements

Implemented targeted fixes including contrast corrections and code-level improvements to meet web accessibility standards (WCAG compliance).

Back-End Architecture Modifications

Navigated and modified the site's back-end architecture to apply audit findings consistently across the codebase.

Social Media Content Creation

Designed and produced short-form video assets for Instagram Reels and other social platforms tied to book promotion campaigns.

Iterative Client Collaboration

Collaborated directly with the client through feedback cycles to refine deliverables and ensure content aligned with marketing objectives.

Implementation Highlights
