Arise

A collaborative habit tracker for building consistency through simple daily and monthly progress tracking

Overview and Summary

Arise is a web-based habit tracker application built collaboratively and published via GitHub. It is designed to help users build and maintain positive habits by monitoring their daily and monthly progress through a clean, multi-page interface with a custom logo and branded color theme.


The application lets users create habits, record their activity, and view progress in a streamlined experience. I contributed to front-end development using HTML, CSS, and JavaScript, built the monthly habits display page, built the edit habits page, implemented responsive navigation for seamless routing, and applied UI theming to match the application's brand identity.


Arise was built to make habit tracking feel straightforward and approachable while still leaving room for future expansion into a more flexible personal tracker.
